# 给定一个带权连通无向图，找一棵包含所有节点、总边权最小的树。
- "树"的约束 — 选出的边必须满足：连通所有 V 个节点，恰好有 V-1 条边，无环。缺一不可。
- "生成" — 必须覆盖图中每一个节点，不能遗漏。
- "最小" — 在所有合法的生成树里，边权之和最小的那一棵。
- MST 不一定唯一（当有相同权重的边时可能存在多棵），但最小总权重是唯一的。


# Kruskal's Algorithm 
- 是求**最小生成树（Minimum Spanning Tree, MST）**的经典贪心算法。核心思路极其简单：每次选最便宜的边，只要不形成环，就加入树里，直到连通所有节点


# 算法步骤
- 将所有边按权重从小到大排序
- 用 Union-Find（并查集）追踪哪些节点已经连通
- 依次考察每条边：若两端节点不在同一集合，则加入 MST；否则跳过（加入会成环）
- 重复直到 MST 有 V-1 条边（V = 节点数）


# union-find
- 是一个管理**"分组"**的数据结构，支持两个操作：
- Union：把两个元素合并到同一组
- Find：查询某个元素属于哪一组

# 核心思想
- 每个节点有一个 parent 指针，find(x) 顺着指针一路往上找到根节点，根相同 = 同一组。
