- 核心思想
LCS 用一张 (m+1) × (n+1) 的二维表 dp[i][j] 记录子问题答案：X 的前 i 个字符与 Y 的前 j 个字符的最长公共子序列长度。
递推公式

边界，base case：
dp[i][0] = dp[0][j] = 0

转移方程：
if X[i] == Y[j]:      
	dp[i][j] = dp[i-1][j-1] + 1      ← 斜向延伸
else:                  
	dp[i][j] = max(dp[i-1][j], dp[i][j-1])  ← 取上/左最大

最终答案：dp[m][n]


当 X[i] ≠ Y[j]，这两个字符不可能同时出现在同一个公共子序列末尾。
所以你必须"放弃"其中一个，看放弃哪个损失更小：
dp[i-1][j]：放弃 X[i]，看 X前i-1个字符 vs Y前j个字符的最优解
dp[i][j-1]：放弃 Y[j]，看 X前i个字符 vs Y前j-1个字符的最优解


- 回溯
核心逻辑就三条规则，按优先级依次判断：

X[i] == Y[j] → 这格是匹配格，记录字符，斜向走（i-1, j-1）
dp[i-1][j] > dp[i][j-1] → 上面更大，向上走
否则 → 向左走
