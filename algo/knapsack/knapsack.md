

#  问题定义
- 给定 n 个物品，每个物品有重量 w_i​ 和价值 v_i，背包容量为 W。每个物品只能选一次，求装入物品的最大总价值。

# 状态定义
- dp[i][w] = 只考虑前 i 个物品、背包容量为 w 时能取到的最大价值。

# base case
- dp[0][w] = 0,  对所有 w ∈ [0, W]   // 没有物品可选，价值为 0
- dp[i][0] = 0,  对所有 i ∈ [0, n]   // 背包容量为 0，装不了任何东西


# 转移方程，下面取更大的
- // 不选物品 i
- dp[i][w] = dp[i-1][w]

- // 选物品 i（前提：w >= wt[i]）
- dp[i][w] = dp[i-1][w - wt[i]] + val[i]

```
if w < wt[i]:
    dp[i][w] = dp[i-1][w]           # 放不下，只能不选
else:
    dp[i][w] = max(dp[i-1][w],      # 不选
                   dp[i-1][w-wt[i]] + val[i])  # 选
```

# 最终答案
- dp[n][W]


# 反向回溯，w=W那列
```
w = W
for i in range(n, 0, -1):
    if dp[i][w] != dp[i-1][w]:   # 价值变化，说明第 i 个物品被选了
        selected.append(i)
        w -= wt[i]
```
