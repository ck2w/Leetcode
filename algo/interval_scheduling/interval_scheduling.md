
# Interval Scheduling
- 问题的核心是：给定一组区间，每个区间有开始时间和结束时间，选出最多数量的互不重叠区间。

# greedy
- 按结束时间排序所有区间
- 初始化 last_end = -∞，count = 0
- 遍历每个区间：若其开始时间 ≥ last_end，则选中它，更新 last_end，count++


# 原理
- 结束得越早，给后面留的空间越多。
- 我们不在乎区间从哪里开始，只在乎它什么时候'让出位置'。一个区间结束越早，后面能塞进去的区间就越多。所以每次都选当前能选的、最早结束的那个——它的代价最小，贪占的时间轴最少。
- 如果你质疑说'万一有个更好的选择'，我可以反问你：把那个'更好的'换成我贪心选的这个，结束时间只会更早或相同，后面的区间完全不受影响——所以换了只会更好，不会更差。"
